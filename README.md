# Maze solver algorithm:
We choose the Breadth-First-Search algorithm to find the solution of the maze because it find inevitably the shortest path between the entry and the exit of a maze.
To do so it explore all cells close to the current cell and save the previous visited cells until he find the exit.
On the other side, it cost a lot of memory depending to the maze size.
